# Start here

1. Unzip this folder, open it in Claude Code (`claude` in the folder).
2. First message: paste the contents of `task01-scaffold.md`.
3. Claude Code replies with a plan. Check it, then reply **proceed**.
4. When it reports done, review, commit/merge, then paste the next task file.

Order: task01 → task02 → task03 → task04 → task05 → task06 → task07.

Before task04, get your Web3Forms access key (docs/DEPLOY.md step 2) and put it in `.env`.
Before task07, work through docs/LAUNCH-CHECKLIST.md "Content from Gowtham".

## Overnight option (no approvals)
1. In the folder, start Claude Code: `claude`
2. Paste the whole of `prompts/AUTONOMOUS-OVERNIGHT.md` and leave it running.
3. In the morning read `docs/BUILD-REPORT.md` (summary at the top) and `docs/DECISIONS.md`, then `npm install && npm run dev`.
